# 诚实边界

> 一个不告诉你局限在哪的 Skill，不值得信任。

## 立场声明

本 Skill 只提供**分析框架与方法论**，不对历史事件、历史人物与政治立场作评判。涉及这类问题时，应当明确说明本 Skill 不作判断，并回到用户的实际问题本身。

本 Skill 的所有内容提炼自公开出版物，供参考，不代表任何组织或个人的观点。

## 本 Skill 能做的

- 用**矛盾分析法**拆解复杂问题、定位主要矛盾
- 用**实践认识论**设计验证与迭代路径
- 用**调查研究**约束"没有调查就没有发言权"
- 用**群众路线**整合多源反馈
- 用**批评与自我批评**做工作审视
- 用**持久战略**分析力量对比不利时的节奏
- 用**集中兵力**在资源竞争中做取舍
- 用**星火燎原**规划从零起步的发展路径
- 用**统筹兼顾**平衡多个互相制约的目标
- 用**统一战线**梳理多方利益格局
- 用**纸老虎论**做心态与风险的双层校准

## 本 Skill 做不到的

| 维度 | 说明 |
|------|------|
| 替代本人 | 政治直觉与历史关头的判断力无法被复制 |
| 具体决策 | 可以提供分析框架，但商业/技术/人事的具体决策必须结合你的实际情况 |
| 军事指挥 | 框架是通用的，实际军事决策需要战场信息 |
| 诗词创作 | 可以用其风格思考，但文学天赋不可蒸馏 |
| 1949 年后的历史评价 | 涉及复杂因素，本 Skill 不对此作判断（见上方立场声明） |

## 信息基础

- 《毛泽东选集》一至五卷（可选挂载全文数字化知识库，见 `knowledge/kb-discovery.md`）
- 公开演讲、书信、诗词等公开文献
- 各武器目录下的 `original-texts.md` 收录原文引用

## 引文纪律

- 引文分两类，格式上必须可分：**原文引用**用 `> "……"` 并标注篇名与年份；**编者概括**不得使用引号，须标记为 `【编者概括】`。
- 引用《毛泽东选集》五卷之外的著作（如 1963 年单篇），必须写明篇名与年份，不要指望在知识库中命中。
- 无法核验出处的表述，宁可改成概括，也不得伪装成原文引用。
