# 外挂知识库：《毛泽东选集》全文（可选）

本 Skill 可挂载《毛泽东选集》全文数字化版本作为外部知识库，用于检索原文、精确引用、查证细节。

**核心原则**：知识库是可选增强，不是依赖。即使没有知识库，本 Skill 内置的十一件思想武器与决策启发式完全足以支撑分析。知识库未找到时，**分析行为**与未配置时完全一致——不主动检索，仅使用内置框架；但用户明确索要原文时须如实说明能力边界（见下方专节），**不静默、不编造**。

## 路径发现

首次需要检索原文时，按以下步骤定位知识库根目录 `KB_ROOT`：

**Step 1 — 环境变量**

执行 `echo $JIAOYUAN_KB_PATH`。如果返回非空路径，且该路径下存在 `src/目录.md`，则使用该路径作为 `KB_ROOT`。

**Step 2 — 约定目录**

依次检查以下路径下是否存在 `src/目录.md`（用 Read 工具尝试读取）：

- `./MaoZeDongAnthology/`（当前工作目录下）
- `../MaoZeDongAnthology/`（父目录下）
- `~/MaoZeDongAnthology/`（Home 目录下）

第一个成功读取的路径即为 `KB_ROOT`。

**Step 3 — 跳过**

以上均未找到 → 设置 `KB_NOT_FOUND=true`，本次会话内不再重复探测。**检索动作**静默跳过，不打断当前任务；但**用户明确索要原文时不得静默**——按下方「知识库不可用时，用户索要原文怎么办」处理。

注意：路径发现是懒加载的——只在会话中首次需要检索原文时才执行，不是每次激活 Skill 都执行。

## 知识库不可用时，用户索要原文怎么办

当 `KB_NOT_FOUND=true`，而用户明确索要原文（如"原文怎么说的""《矛盾论》里那段原话是什么""给我看原文"）时，按以下顺序处理：

1. **先查内置引文**：在各武器的 `original-texts.md` 中查找。用户要的那段若在内置引文中，直接给出，并标注篇名与年份。

2. **内置引文里也没有 → 如实说明能力边界，不得凭记忆复述**。固定表述：

   > 我手上只有各武器目录下已核验的原文引用，没有《毛泽东选集》全文，检索不到你问的这一段。我不会凭记忆复述原文——那样很容易出错。

3. **告知获取方式**（一次性说明，同一会话内不重复打扰）：

   ```
   git clone https://github.com/weiyinfu/MaoZeDongAnthology.git ~/MaoZeDongAnthology
   ```

   装好后放在当前工作目录、父目录或 Home 目录下均可被自动发现，无需配置；也可设环境变量 `JIAOYUAN_KB_PATH` 指向它。

4. **给出可核验的线索**：即使拿不到原文，也要提供篇名与年份（查上方「思想武器 → 源文映射」表），让用户能自行核对。

5. **用户说"我装好了"时**：清除 `KB_NOT_FOUND` 标记，重新执行一次路径发现，不要以"本次会话内不再尝试"为由拒绝。

**禁止**：以"我记得原文是……"的方式复述无法核验的引文。这条由 `dna/boundaries.md` 的引文纪律兜底。

## 检索规则（如果知识库可用）

**何时检索**：

1. 分析涉及《毛泽东选集》中的具体篇目时——读取对应文章
2. 需要引用原文段落作为论据支撑时——搜索相关段落
3. 用户的问题涉及特定历史时期或事件时——查目录定位
4. 用户追问"选集里怎么说的"时——必须回到原文
5. 框架中的引语需要上下文扩展时——读取所在文章的上下文

**如何检索**：

| 需求 | 方法 |
|------|------|
| 找特定篇目 | 根据映射表，直接读取 `KB_ROOT/src/NNN-标题.md` |
| 按主题搜索 | Grep 关键词在 `KB_ROOT/src/` 目录中搜索 |
| 按时期浏览 | 先读 `KB_ROOT/src/目录.md`，定位文章编号范围 |
| 扩展引语上下文 | 已知引语出自某篇，读取全文获取完整脉络 |

**格式提示**：文章一级标题 = 篇名，`>` 开头 = 导读注释，`----------` 之后 = 注释。长文（如《论持久战》）可先用 Grep 定位关键词再读上下文。
